# Handwriting Board

Процедурный генератор реалистичного рукописного почерка (латиница, польские/французские диакритики, кириллица, цифры, пунктуация) с живым редактором текста, ползунком «Спешка» (`0%–100%`) и экспортом в прозрачный PNG (3× retina, автообрезка по тексту).

## Быстрый запуск без ИИ и без сервера

Просто открой собранный файл **`dist/app.html`** в любом браузере (Chrome, Edge, Safari, Firefox):
- Вводи или вставляй любой текст в нижнее поле — он сразу пишется от руки.
- **Спешка `0%`–`100%`**: от старательного аккуратного почерка (`0%`, как `v4-neat`) до беглых конспектов (`50%–100%`).
- **Размер**, **цвет чернил**, **тип ручки**, **🎲 Вариант** (новый `seed`) и **➕ Блок** (добавить отдельный абзац ниже).
- **📋 Без фона** / **⬇ PNG без фона**: прозрачный PNG в 3× качестве без точек и фона доски, готовый к вставке в Noteshelf / заметки / документы.

## Сборка из исходников

```bash
npm install
npm run typecheck
npm run build
```

Результат собирается в один автономный HTML-файл `dist/app.html` (и MCP-сервер `dist/server.js`).

## Теги версий

- `v4-neat` — аккуратный старательный почерк (AR(1) инерция руки, оптический кернинг, монолиния)
- `v5-hurry` — физика беглого письма (зональное приплющивание строчных, ускоренные аллографы, сглаживание углов, ритм) + ползунок «Спешка»
- `v6-editor-export` — встроенное локальное поле ввода текста и экспорт прозрачного PNG без фона
