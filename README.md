# Handwriting Board MCP (`handwriting-board-mcp`)

MCP-сервер (с поддержкой **MCP Apps / SEP-1865**), в котором ИИ-модель пишет на интерактивной графической доске **живым рукописным почерком** — с процедурной генерацией штрихов (кириллица + латиница + цифры), анимацией письма в реальном времени и настраиваемой степенью «пьяности» (`drunkness: 0.0 .. 1.0`).

## Возможности

- **Процедурный рукописный движок (без статичных шрифтов):** каждая буква строится из сплайнов Катмулла-Рома с органическими отклонениями — ни одна `а` или `о` не повторяется дважды.
- **Физика живой и пьяной руки:**
  - `drunkness` (`0.0` — аккуратный трезвый почерк, `1.0` — «в стельку»)
  - Пресеты `mood`: `sober`, `casual`, `hurried`, `tired`, `tipsy`, `drunk`, `wasted`, `doctor` (почерк врача!)
  - Уплывающая и волнообразная строка, дрожание руки (тремор), пляшущий размер и наклон букв, кляксы и случайные касания пером, **зачёркнутые опечатки** (`messy_crossouts`).
- **5 поверхностей доски:** `whiteboard` (маркерная), `notebook` (тетрадь в клетку), `lined` (в линейку), `chalkboard` (школьная доска), `napkin` (барная салфетка со следом от кружки).
- **5 инструментов письма:** `marker`, `ballpoint`, `fountain`, `chalk`, `pencil` — с симуляцией нажима.
- **Интерактивность:** живая анимация с движущимся маркером, дорисовывание мышкой/стилусом, повтор анимации, ускорение (`1x / 2x / 4x`), Undo, Clear, экспорт в PNG.

## MCP-инструменты

- `open_board` — открыть доску (поддерживает inline, боковую панель `aux_pane` и полноэкранный режим `global`).
- `write_handwritten_text` — написать рукописный текст с параметрами `text`, `mood`, `drunkness`, `pen`, `color`, `size`, `x`, `y`, `slant`, `messy_crossouts`, `animate`.
- `draw_doodle` — дорисовать от руки подчёркивание, кружок, стрелку, рамку, звезду, сердечко, зачёркивание или каракули.
- `set_board_style` — сменить поверхность доски или очистить её.
- `get_board_state` — получить текущее состояние доски и координаты.

## Сборка и запуск

```bash
npm install
npm run build
npm start
```

## Подключение

### Как плагин Antigravity
Скопируйте папку проекта (после `npm run build`) в `~/.gemini/config/plugins/handwriting-board/`.

### Через `mcp_config.json` (Antigravity / Claude Desktop / Cursor)
```json
{
  "mcpServers": {
    "handwriting-board": {
      "command": "node",
      "args": ["C:/Users/RangoPA/.gemini/antigravity/scratch/handwriting-board-mcp/dist/server.js"]
    }
  }
}
```

### Быстрый просмотр доски в браузере
После сборки можно просто открыть `dist/app.html` в браузере — запустится встроенное демо (трезвый → подшофе → пьяный почерк).
